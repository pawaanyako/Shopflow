# Shopflow

## Purpose

Pet project for learning .NET microservices

## Key technologies for .NET microservices in 2026

* Language: C# (.NET 9)
* Containerization: Docker, Docker Compose
* Orchestration: Kubernetes (K8s)
* API Gateway: YARP (Yet Another Reverse Proxy) or Ocelot
* Message Broker: RabbitMQ or Apache Kafka
* Service Mesh: maybe Dapr
* CI/CD: GitHub Actions
* Monitoring/Observability: OpenTelemetry, Grafana, Prometheus, Jaeger/Zipkin
* Service Discovery: Consul or built-in K8s
* Database: PostgreSQL per service, Redis for caching
* Authentication: Keycloak or IdentityServer (Duende)
* Version Control: Git
* Testing: xUnit, integration tests
* gRPC: for inter-service communication
* Health checks: ASP.NET Core health checks

## Services

* Identitiy

* Orders
